### 复习和巩固的知识点

1. **国民储蓄恒等式 S = I**
   - 封闭经济中，国民储蓄必然等于投资
   - 公式推导：Y = C + I + G → I = Y - C - G = (Y - T - C) + (T - G) = 私人储蓄 + 公共储蓄

2. **三种储蓄的精确定义与计算**
   - 私人储蓄 = Y - T - C（家庭收入减去税收再减去消费）
   - 公共储蓄 = T - G（税收减去政府支出）
   - 国民储蓄 = 私人储蓄 + 公共储蓄

3. **可贷资金市场模型**
   - 供给方：储蓄者（国民储蓄）
   - 需求方：借款者/投资者
   - 价格：真实利率
   - 均衡：利率调节使储蓄等于投资

4. **三大政策分析（全部掌握）**
   - 储蓄激励：供给曲线右移 → 利率下降 → 投资增加
   - 投资激励：需求曲线右移 → 利率上升 → 投资增加
   - 政府赤字：供给曲线左移 → 利率上升 → 私人投资减少（挤出效应）

5. **增税案例的深层分析**
   - 增税不改变总投资量（国民储蓄不变）
   - 但改变储蓄结构：私人储蓄减少，公共储蓄增加
   - 政府从"借钱"变为"存钱"，减少了对私人储蓄的"竞争"
