# 曼昆《经济学原理》第七版学习仓库

🎓 **使用 AI 辅助学习曼昆经典经济学教材**

这是我的个人学习仓库，用于系统学习曼昆（N. Gregory Mankiw）的《经济学原理》第七版。借助 Claude Code 的苏格拉底式教学法，让经济学学习更加高效和深入。

---

## 📚 关于教材

**曼昆《经济学原理》第七版**是经济学领域最经典的入门教材之一，分为两大部分：
- **微观经济学**（第1-22章）：个人、企业和市场的决策
- **宏观经济学**（第23-36章）：整体经济运行与政策

本书以"经济学十大原理"为核心框架，通过大量现实案例帮助读者建立经济学思维。

---

## 🎯 这个仓库如何工作

这个仓库使用 Claude Code 作为你的**私人经济学导师**：

- **苏格拉底式教学**：先问你已知什么，而非直接灌输
- **简洁解释**：约200字的精炼概念讲解
- **即时检验**：通过问题验证你的理解
- **自适应学习**：根据你的回答调整教学风格
- **进度追踪**：自动记录每次学习内容

## 🚀 如何开始

### 日常学习流程

1. 在 Claude Code 中打开这个仓库
2. 像聊天一样问经济学问题：
   - "给我讲解机会成本的概念"
   - "用供需曲线解释房价上涨"
   - "比较优势和国际贸易有什么关系？"
3. 回答 Claude 提出的理解检验问题
4. 每次会话结束后，Claude 会自动记录：
   - 学习内容
   - 掌握程度
   - 薄弱环节
   - 下次复习建议

### 复习建议

你可以随时问 Claude：
- "复习一下我最近学过的内容"
- "我有哪些知识缺口需要补强？"
- "用经济学原理解释一下最近的某个新闻"
- "显示我的学习进度"

Claude 会读取你的学习历史，提供个性化的复习内容。

### 查看学习进度

打开 `/progress/economics-study-tracker.md` 查看：
- 总体学习进度
- 各章节掌握情况
- 知识点清单
- 学习计划安排

## 📖 学习路径建议

### 第一阶段：基础建立（第1-6章）
- 理解经济学十大原理
- 掌握供需分析框架
- 学会计算弹性

### 第二阶段：市场与福利（第7-12章）
- 消费者和生产者剩余
- 市场效率分析
- 市场失灵与政府干预

### 第三阶段：产业组织（第13-17章）
- 企业成本分析
- 不同市场结构的特征
- 竞争与垄断

### 第四阶段：宏观基础（第23-30章）
- GDP与物价衡量
- 经济增长理论
- 货币与通货膨胀

### 第五阶段：政策应用（第31-36章）
- 开放经济宏观经济学
- 短期经济波动
- 宏观政策争论

## 💡 学习理念

**引导式学习方法**：
- 对话式、无压力的学习环境
- 建立在你已有知识之上
- 在继续前先检查理解程度
- 适应你的学习风格
- 注重深度理解而非死记硬背
